# Catalog provenance

Everything under `catalog_data/` is original text written for HomeKeep (TDD §2, BRD D01).

- **Brand and models:** "Frostline" FL-18i and FL-24x are fictional. Any resemblance to a real product is unintended.
- **Manuals** (`sources/`): synthetic. `malicious-manual.md` contains an injected instruction on purpose, for AT-10.
- **Approved speech text** (`models/*.json`, `hazards.json`, `generic_prompts.json`, `intake/`): written under the `elder-voice-copy` rules. The pull request that adds or changes it is the review record (FR-23). Steps never require climbing, opening covers, refrigerant or wiring.
- **Status:** FL-18i v2 is published and v1 is withdrawn (AT-24). The two FL-24x sources disagree on E4, so no model-specific step is given for E4 (AT-04).
